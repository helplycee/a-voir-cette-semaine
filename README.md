# À voir cette semaine

Module affiché sur les Google Sites des classes : chaque semaine, un film, une série, un documentaire ou une émission
diffusé gratuitement sur la TNT (ou en replay gratuit), en lien avec le programme de la classe.

- `index.html` : le module (lit `data.json`).
- `data.json` : les recommandations de la semaine, une par classe. **C'est le seul fichier modifié chaque vendredi.**
